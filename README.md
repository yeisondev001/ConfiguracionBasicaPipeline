# 🚀 Proyecto CI/CD Simple con GitHub Actions

## 📋 Descripción
Este proyecto muestra una aplicación web sencilla con un pipeline CI/CD automatizado.

## ⚙️ Requisitos técnicos
- Cuenta de GitHub
- Conocimientos básicos de Git
- Editor de código (VSCode recomendado)
- Node.js instalado localmente (opcional)

## 🧠 Tareas realizadas
1. **Configuración inicial**
   - Repositorio en GitHub
   - Estructura del proyecto
   - `index.html` básico
2. **Pruebas**
   - Prueba unitaria y de integración en `test.js`
3. **Pipeline**
   - Workflow que ejecuta pruebas y despliega automáticamente a GitHub Pages
4. **Documentación**
   - Este README con guía de despliegue y contribución

## ▶️ Cómo desplegar
1. Sube todos los archivos a tu repositorio.
2. Activa **GitHub Pages** en la rama `gh-pages`.
3. GitHub Actions hará el resto automáticamente.

## 🤝 Guía de contribución
1. Haz un fork del repositorio.
2. Crea una rama (`feature-nueva`).
3. Haz tus cambios y crea un Pull Request.
